What You Will Learn

Object-Oriented Design

Design software using classes, objects, inheritance, polymorphism, encapsulation, abstraction, and UML.

Modern Java

Work with generics, collections, exceptions, file I/O, serialization, threads, lambda expressions, and other modern Java programming concepts.

Software Development

Develop larger applications using databases, JDBC, JPA, web application architectures, Spring Boot, and microservices.
